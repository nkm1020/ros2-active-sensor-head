# Project Log

Use this file to record implementation decisions and learning that was immediately applied to the project. Add the newest entry at the top.

## Entry template

### YYYY-MM-DD | Milestone M?

**Observable behavior wanted**

Describe one thing that should work and how it will be observed.

**Smallest implementation attempt**

Describe what was tried before studying a broader topic.

**Exact blocker**

Record the error, unexpected behavior, or missing concept precisely. Include the relevant command or short error excerpt, but never secrets or tokens.

**Minimum knowledge learned**

State only the concept learned to remove the blocker.

**Change applied**

List the files or parameters changed and explain why.

**Test and result**

Record the command, input conditions, output, metric, and whether the milestone gate passed.

**What I can now explain or modify**

Write what can be explained without reading generated code and one modification that can be made independently.

**Evidence**

Link the commit, plot, CSV, screenshot, rosbag, or video.

**Next observable behavior**

Define the next smallest working feature.
